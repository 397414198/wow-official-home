# LoneWalkerLee 高大上官网首页

正式官网风格，需要你自己准备官方高清图片。

## 必须准备的图片
把下载好的官方壁纸放到 assets/ 文件夹：

1. **hero.jpg**（最重要）
   - 全屏英雄背景图
   - 推荐尺寸：1920×1080 或更高
   - 去 Blizzard 官网或 Press Center 下载任意一张史诗风景/角色 key art

## 推荐下载地址
- https://blizzard.gamespress.com/World-of-Warcraft
- https://worldofwarcraft.blizzard.com （媒体/壁纸区）
- Warcraft Wiki Wallpaper 页面

## 部署
上传整个文件夹到 GitHub → Cloudflare Pages（Framework: None，输出目录: /）
